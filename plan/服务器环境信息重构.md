# 服务器环境信息重构：探测脚本 + 后端数据 + 前端展示

## Context

当前服务器探测存在以下问题：
1. **GPU 数量显示错误**：只显示用户已选 GPU 数量（如 1 张），而非服务器实际物理总数（如 8 张）
2. **数据冗余**：「显卡型号」和「显卡数量/编号」存在信息重复
3. **硬件信息缺失**：缺少 CPU、内存数据
4. **展示不直观**：6 个扁平 Info 卡片无法展示结构化数据，微调环境信息分散

目标：重构探测脚本采集完整硬件数据，后端采用结构化 JSON 存储，前端按设计稿（`server_environment_layout_preview.jsx`）实现 3 卡片布局，支持 light/dark 主题。

### 1.1 探测脚本增强 — `backend/app/services/script_service.py`

**`SERVER_HARDWARE_PROBE_TEMPLATE` 新增采集项：**

```python
# CPU 信息
def detect_cpu():
    model = run("grep 'model name' /proc/cpuinfo | head -1 | cut -d: -f2", name="cpu_model")
    cores = run("grep -c ^processor /proc/cpuinfo", name="cpu_cores")
    threads = run("nproc", name="cpu_threads")
    return {"model": model.strip(), "cores": int(cores or 0), "threads": int(threads or 0)}

# 内存信息
def detect_memory():
    out = run("free -b | grep Mem", name="memory")
    parts = out.split()
    # total, used, free, shared, buff/cache, available
    if len(parts) >= 3:
        return {"total": int(parts[1]), "used": int(parts[2]),
                "percent": round(int(parts[2]) / int(parts[1]) * 100) if int(parts[1]) else 0}
    return None

# GPU 全量（不受 GPU_IDS 选择过滤）
all_gpu_lines = [l for l in accelerator["csv"].splitlines() if l.strip()]
all_ids = [l.split(",")[0].strip() for l in all_gpu_lines]
total_count = len(all_gpu_lines)
```

**payload 输出新增字段：**
```python
"cpu": detect_cpu(),
"memory": detect_memory(),
"total_gpu_count": total_count,      # 物理总数
"all_gpu_ids": all_ids,              # 全部可见编号
"gpu_model": rows[0][1] if rows else "-",  # 纯型号名
```

**`SERVER_FINETUNE_ENV_PROBE_TEMPLATE`：** 结构不变，仅确保字段名一致。

### 2.4 表格列重构 — 7 列

| 列 | 数据来源 | 宽度策略 |
|----|---------|---------|
| 服务器名称 | `s.name` | 弹性，min-width |
| 连接地址 | `jupyterBaseUrl` 或 `host` | 弹性 |
| 连接方式 | `accessType` | 固定窄列 |
| 状态 | `status` → Badge | 固定窄列 |
| 微调工具 | `finetuneToolName` + `finetuneEnvInfo.llamafactory` | 中等 |
| 显卡型号 | `gpuInfo.model` + `gpuInfo.physicalCount` → `"8×A800-80GB"` | 弹性 |
| 磁盘 | `hardwareInfo.disk` → 进度条 | 中等，含进度条 |

**GPU 列显示逻辑：** `gpuInfo.physicalCount × gpuInfo.model`（去掉 "NVIDIA" 前缀节省空间）
**磁盘列显示逻辑：** `hardwareInfo.disk.used / hardwareInfo.disk.total` + MiniProgress
