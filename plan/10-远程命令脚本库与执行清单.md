# 远程命令脚本库与执行清单

> 状态：[草案]  
> 创建时间：2026-05-21  
> 最后更新：2026-05-21

## 1. 设计目标

远程命令不能散落在代码中硬编码。系统需要一个可管理、可版本化、可测试、可审计的脚本库。

脚本库用于支持：

- 服务器环境探测。
- GPU 状态读取。
- 工作目录检查和创建。
- LLaMA-Factory 环境校验。
- 配置文件同步。
- 训练启动、停止、状态读取。
- 日志增量读取。
- 远程目录刷新。
- 评测启动和结果读取。

## 2. 脚本模板模型

表：`script_templates`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| key | string | 脚本唯一键，如 `server.probe_env` |
| name | string | 展示名称 |
| category | string | `server` / `train` / `log` / `eval` / `file` |
| version | int | 版本号 |
| status | enum | `draft` / `active` / `disabled` / `archived` |
| description | text | 说明 |
| shell | enum | `bash` / `python` / `mixed` |
| template | text | 脚本模板 |
| param_schema | json | 参数 schema |
| output_type | enum | `json` / `text` / `log_chunk` |
| parser_type | enum | `json` / `regex` / `builtin` / `none` |
| timeout_ms | int | 默认超时 |
| allow_parallel | bool | 是否允许并发 |
| risk_level | enum | `low` / `medium` / `high` |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

表：`script_template_versions`

保留每次变更前的历史版本，支持回滚。

## 3. 参数渲染规范

脚本模板使用 `{{param}}` 占位。后端渲染前必须：

- 校验参数 schema。
- 对 shell 参数做安全转义。
- 文件内容使用 base64 传输，避免引号破坏。
- 禁止未声明参数。

推荐参数类型：

| 类型 | 用途 |
|---|---|
| `string` | 普通文本 |
| `path` | 远程路径，必须限制在工作目录内 |
| `gpu_ids` | GPU 列表，如 `0,1` |
| `base64_text` | 文件内容 |
| `integer` | 数字 |
| `enum` | 固定选项 |

## 4. 内置脚本清单

### 4.1 server.probe_env

用途：探测服务器和容器环境。

触发页面：服务器管理页连通性检查。

参数：

| 参数 | 说明 |
|---|---|
| work_dir | 工作目录 |
| gpu_ids | 当前逻辑服务器绑定 GPU |

脚本：

```bash
python3 - <<'PY'
import json, os, subprocess, sys

WORK_DIR = """{{work_dir}}"""
GPU_IDS = """{{gpu_ids}}"""

def run(cmd, timeout=15):
    try:
        return subprocess.check_output(cmd, shell=True, stderr=subprocess.STDOUT, text=True, timeout=timeout).strip()
    except Exception:
        return ""

def disk(path):
    out = run(f"df -B1 --output=size,used,avail,pcent,target {path!r} 2>/dev/null | tail -1")
    parts = out.split()
    if len(parts) >= 5:
        return {
            "size": int(parts[0]),
            "used": int(parts[1]),
            "avail": int(parts[2]),
            "percent": parts[3],
            "target": parts[4],
        }
    return None

gpu_csv = run("nvidia-smi --query-gpu=index,name,uuid,memory.total,memory.used --format=csv,noheader,nounits")
torch_info = run("python3 - <<'PY2'\nimport json\ntry:\n import torch\n print(json.dumps({'torch': torch.__version__, 'cuda': torch.version.cuda, 'cuda_available': torch.cuda.is_available()}))\nexcept Exception as e:\n print(json.dumps({'error': str(e)}))\nPY2")

payload = {
    "hostname": run("hostname"),
    "pwd": os.getcwd(),
    "work_dir": WORK_DIR,
    "work_dir_exists": os.path.exists(WORK_DIR),
    "work_dir_writable": os.access(WORK_DIR, os.W_OK) if os.path.exists(WORK_DIR) else False,
    "python": sys.version.split()[0],
    "torch_info": torch_info,
    "driver": run("nvidia-smi --query-gpu=driver_version --format=csv,noheader,nounits | head -1"),
    "gpus_csv": gpu_csv,
    "selected_gpu_ids": GPU_IDS,
    "llamafactory": run("llamafactory-cli version 2>/dev/null || python3 -m llamafactory.cli version 2>/dev/null"),
    "disk": disk(WORK_DIR if os.path.exists(WORK_DIR) else "/"),
}
print(json.dumps(payload, ensure_ascii=False))
PY
```

输出：JSON。

超时：30 秒。

### 4.3 server.gpu_status

用途：读取 GPU 实时占用。

脚本：

```bash
nvidia-smi --query-gpu=index,name,uuid,memory.total,memory.used,utilization.gpu --format=csv,noheader,nounits
echo "__PROCESS__"
nvidia-smi --query-compute-apps=gpu_uuid,pid,process_name,used_memory --format=csv,noheader,nounits 2>/dev/null || true
```

解析：

- `__PROCESS__` 前是 GPU 列表。
- 后面是当前计算进程。

### 4.4 file.write_base64

用途：写远程文件。

参数：

| 参数 | 说明 |
|---|---|
| target_path | 目标路径 |
| content_b64 | 文件内容 base64 |
| mode | 权限，如 `0644` |

脚本：

```bash
python3 - <<'PY'
import base64, json, os
target = """{{target_path}}"""
content = """{{content_b64}}"""
mode = int("""{{mode}}""", 8)
os.makedirs(os.path.dirname(target), exist_ok=True)
with open(target, "wb") as f:
    f.write(base64.b64decode(content))
os.chmod(target, mode)
print(json.dumps({"path": target, "bytes": os.path.getsize(target)}, ensure_ascii=False))
PY
```

### 4.5 subtask.sync_config

用途：同步子任务配置文件。

参数：

| 参数 | 说明 |
|---|---|
| subtask_dir | 子任务目录 |
| train_yaml_b64 | train.yaml |
| dataset_info_b64 | dataset_info.json |
| run_sh_b64 | run.sh |

脚本：

```bash
python3 - <<'PY'
import base64, json, os
subtask_dir = """{{subtask_dir}}"""
files = {
  "train.yaml": """{{train_yaml_b64}}""",
  "dataset_info.json": """{{dataset_info_b64}}""",
  "run.sh": """{{run_sh_b64}}""",
}
os.makedirs(subtask_dir, exist_ok=True)
os.makedirs(os.path.join(subtask_dir, "logs"), exist_ok=True)
os.makedirs(os.path.join(subtask_dir, "outputs"), exist_ok=True)
os.makedirs(os.path.join(subtask_dir, "eval"), exist_ok=True)
written = []
for name, b64 in files.items():
    path = os.path.join(subtask_dir, name)
    with open(path, "wb") as f:
        f.write(base64.b64decode(b64))
    if name.endswith(".sh"):
        os.chmod(path, 0o755)
    written.append(path)
print(json.dumps({"subtask_dir": subtask_dir, "written": written}, ensure_ascii=False))
PY
```

### 4.6 subtask.start_train

用途：后台启动训练。

参数：

| 参数 | 说明 |
|---|---|
| subtask_dir | 子任务目录 |

脚本：

```bash
cd "{{subtask_dir}}"
mkdir -p logs
if [ -f run.pid ] && kill -0 "$(cat run.pid)" 2>/dev/null; then
  echo '{"started":false,"reason":"already_running"}'
  exit 0
fi
nohup bash run.sh >> logs/stdout.log 2>&1 &
pid=$!
echo "$pid" > run.pid
python3 - <<PY
import json, time
print(json.dumps({"started": True, "pid": $pid, "started_at": time.time()}, ensure_ascii=False))
PY
```

### 4.7 subtask.poll_status

用途：读取训练状态。

参数：

| 参数 | 说明 |
|---|---|
| subtask_dir | 子任务目录 |

脚本：

```bash
cd "{{subtask_dir}}"
python3 - <<'PY'
import json, os

def alive(pid):
    try:
        os.kill(pid, 0)
        return True
    except Exception:
        return False

payload = {"pid": None, "pid_alive": False, "status": "unknown", "exit_code": None}
if os.path.exists("run.pid"):
    try:
        payload["pid"] = int(open("run.pid").read().strip())
        payload["pid_alive"] = alive(payload["pid"])
    except Exception:
        pass
if os.path.exists("status.json"):
    try:
        status = json.load(open("status.json"))
        payload.update(status)
    except Exception as e:
        payload["status_parse_error"] = str(e)
elif payload["pid_alive"]:
    payload["status"] = "running"
print(json.dumps(payload, ensure_ascii=False))
PY
```

### 4.8 subtask.read_log_since

用途：读取日志增量。

参数：

| 参数 | 说明 |
|---|---|
| log_file | 日志路径 |
| offset | 字节偏移 |
| max_bytes | 最大读取字节 |

脚本：

```bash
python3 - "{{log_file}}" "{{offset}}" "{{max_bytes}}" <<'PY'
import base64, json, os, sys
path = sys.argv[1]
offset = int(sys.argv[2])
max_bytes = int(sys.argv[3])
payload = {"exists": os.path.exists(path), "offset": offset, "next_offset": offset, "content_b64": ""}
if payload["exists"]:
    size = os.path.getsize(path)
    if offset > size:
        offset = 0
    with open(path, "rb") as f:
        f.seek(offset)
        data = f.read(max_bytes)
    payload["offset"] = offset
    payload["next_offset"] = offset + len(data)
    payload["content_b64"] = base64.b64encode(data).decode()
    payload["size"] = size
print(json.dumps(payload, ensure_ascii=False))
PY
```

### 4.9 subtask.stop_train

用途：停止训练。

参数：

| 参数 | 说明 |
|---|---|
| subtask_dir | 子任务目录 |
| grace_seconds | 温和停止等待秒数 |

脚本：

```bash
cd "{{subtask_dir}}"
python3 - "{{grace_seconds}}" <<'PY'
import json, os, signal, sys, time
grace = int(sys.argv[1])
payload = {"stopped": False, "reason": ""}
if not os.path.exists("run.pid"):
    payload["reason"] = "pid_file_missing"
    print(json.dumps(payload, ensure_ascii=False))
    raise SystemExit(0)
pid = int(open("run.pid").read().strip())
try:
    os.kill(pid, signal.SIGTERM)
except ProcessLookupError:
    payload["stopped"] = True
    payload["reason"] = "already_exited"
    print(json.dumps(payload, ensure_ascii=False))
    raise SystemExit(0)
for _ in range(grace * 10):
    try:
        os.kill(pid, 0)
        time.sleep(0.1)
    except ProcessLookupError:
        payload["stopped"] = True
        payload["reason"] = "terminated"
        break
else:
    try:
        os.kill(pid, signal.SIGKILL)
        payload["stopped"] = True
        payload["reason"] = "killed"
    except Exception as e:
        payload["reason"] = str(e)
open("status.json", "w").write(json.dumps({"status": "stopped", "exit_code": None, "updated_at": time.time()}))
print(json.dumps(payload, ensure_ascii=False))
PY
```

## 5. 命令执行等级

| 风险等级 | 示例 | 管控 |
|---|---|---|
| low | 读取环境、读取日志、列目录 | 可直接执行 |
| medium | 创建目录、写配置、启动训练 | 需要业务 API 调用 |
| high | 停止进程、删除目录、部署容器 | 需要确认和审计 |

## 6. 脚本测试规范

每个脚本模板都必须支持测试：

- 参数 schema 校验。
- dry-run 渲染。
- 在测试服务器执行。
- 校验输出 parser。
- 记录测试历史。

测试记录表：`script_test_runs`

| 字段 | 说明 |
|---|---|
| id | BIGINT，内部存储 ID，雪花算法 long，不对外展示 |
| script_key | 脚本 key |
| script_version | 版本 |
| server_profile_id | 测试服务器 |
| params_json | 参数 |
| rendered_script | 渲染结果 |
| status | 成功/失败 |
| output | 输出 |
| error_message | 错误 |
| created_at | 时间 |
