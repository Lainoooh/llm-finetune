## 1. 核心领域概念

系统核心不是“远程命令执行”，而是“可调度训练资源 + 微调任务编排”。领域模型需要围绕以下对象设计：

- 物理服务器
- 逻辑服务器对象
- GPU 设备
- 运行环境快照
- LLaMA-Factory 容器镜像
- 微调任务
- 微调子任务
- 数据集
- 训练配置
- 执行记录
- 训练日志
- 评测结果
- 远程命令任务

## 1.1 ID 设计约定

所有数据库表的存储主键统一使用雪花算法生成的 `BIGINT` / `long` 类型字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法生成，不对外展示 |

业务展示编号单独建字段，不和存储主键混用：

| 业务对象 | 展示编号字段 | 示例 |
|---|---|---|
| 微调任务 | task_code | `ID=bt001` |
| 微调子任务 | subtask_code | `task_002` |
| 执行记录 | run_code | `run_20260521_001`，可选 |

前端页面展示和用户搜索优先使用 `task_code` / `subtask_code`，后端 API 内部关联使用 `id`。如果 API 路径需要对外暴露资源标识，优先使用展示编号或单独的 public key，避免直接暴露存储 ID。

## 2. 物理服务器与逻辑服务器对象

### 2.1 PhysicalServer

表示一台真实机器。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| name | string | 物理服务器名称 |
| host | string | 访问地址 |
| access_type | enum | `jupyter` / `ssh` / `docker` |
| auth_ref | string | 凭据引用，不直接暴露明文 |
| status | enum | `unknown` / `online` / `offline` / `error` |
| last_probe_at | datetime | 最近探测时间 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 2.2 ServerProfile

表示可被子任务选择的逻辑服务器对象。一个物理服务器可以拆成多个 ServerProfile。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| physical_server_id | BIGINT | 所属物理服务器内部 ID |
| name | string | 展示名称，如 `A100-01-GPU0` |
| work_dir | string | 训练工作目录 |
| gpu_ids | string | 该对象允许使用的 GPU，如 `0`、`0,1` |
| finetune_tool | string | 当前为 `LLaMA-Factory` |
| status | enum | `online` / `offline` / `busy` / `disabled` |
| env_snapshot_id | string | 最近环境快照 |
| remark | string | 备注 |

说明：

- 当前前端 `servers` 更接近 `ServerProfile`，不是严格的物理服务器。
- 后续 UI 可以先不显式拆出 PhysicalServer，但数据层应预留。

### 2.3 GPUDevice

表示物理服务器上的单张 GPU。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| physical_server_id | BIGINT | 所属物理服务器内部 ID |
| index | int | GPU 序号 |
| uuid | string | GPU UUID |
| name | string | 型号 |
| memory_total_mb | int | 总显存 |
| driver_version | string | 驱动版本 |
| cuda_version | string | CUDA 版本 |
| current_status | enum | `idle` / `locked` / `external_busy` / `unknown` |

## 3. 环境快照

### 3.1 RuntimeEnvironmentSnapshot

一次探测结果。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| server_profile_id | BIGINT | 对应逻辑服务器内部 ID |
| captured_at | datetime | 探测时间 |
| hostname | string | 容器/主机名 |
| gpu_summary | string | 页面展示文本 |
| cuda_version | string | CUDA |
| torch_version | string | PyTorch |
| python_version | string | Python |
| llamafactory_version | string | LLaMA-Factory |
| disk_used_tb | number | 工作目录或根目录已用 |
| disk_total_tb | number | 总容量 |
| raw_json | json | 原始探测结果 |

当前前端字段映射：

| 前端字段 | 目标字段 |
|---|---|
| `gpu` | `gpu_summary` |
| `cuda` | `cuda_version` |
| `torch` | `torch_version` |
| `finetuneTools["LLaMA-Factory"]` | `llamafactory_version` |
| `disk` | 由 `disk_used_tb` / `disk_total_tb` 格式化 |
| `status` | `ServerProfile.status` |

## 4. 微调任务模型

### 4.1 FineTuneTask

微调任务是目标阶段的统称，不直接执行训练。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| task_code | string | 业务展示编号，如 `ID=bt001` |
| name | string | 任务名称 |
| model_name | string | 目标模型名 |
| base_model | string | 基座模型 |
| status | enum | 聚合状态 |
| description | string | 任务说明 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

任务状态由子任务聚合：

| 子任务情况 | 任务状态 |
|---|---|
| 无子任务或未启动 | `draft` / `waiting` |
| 任意子任务 running | `running` |
| 全部结束且至少一个成功 | `succeeded` |
| 全部结束且全部失败 | `failed` |
| 人工暂停 | `paused` |

### 4.2 FineTuneSubtask

子任务是一次完整微调训练的执行对象。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| subtask_code | string | 业务展示编号，如 `task_002` |
| task_id | BIGINT | 所属任务内部 ID |
| name | string | 子任务名称 |
| server_profile_id | BIGINT | 绑定逻辑服务器内部 ID |
| gpu_ids | string | 实际使用 GPU，默认来自服务器对象 |
| status | enum | `draft` / `queued` / `running` / `succeeded` / `failed` / `stopped` |
| base_model_path | string | 基模路径 |
| output_dir | string | 输出目录 |
| train_dataset | string | 训练集 |
| eval_dataset | string | 评测集 |
| train_config_id | string | 训练配置 |
| latest_run_id | string | 最近执行记录 |
| loss | number | 最近训练 loss |
| score | number | 最近评测分 |

## 5. 训练配置模型

### 5.1 TrainConfig

用于生成 LLaMA-Factory YAML。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| subtask_id | BIGINT | 子任务内部 ID |
| stage | string | 如 `sft` |
| finetuning_type | string | 如 `lora` |
| learning_rate | string | 如 `5e-5` |
| num_train_epochs | number | epoch |
| per_device_train_batch_size | number | batch size |
| save_steps | number | 保存间隔 |
| cutoff_len | number | 上下文长度 |
| bf16 | boolean | 是否 bf16 |
| lora_rank | number | LoRA rank |
| raw_yaml | text | YAML 模式下的原文 |

原则：

- 可视化表单是结构化配置的主视图。
- YAML 是高级编辑视图。
- 二者应可互相转换，但 YAML 中未知字段要保留。

## 6. 执行记录模型

### 6.1 ExecutionRun

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| target_type | enum | `server_probe` / `train` / `eval` / `file_sync` |
| target_id | BIGINT | 对应服务器或子任务内部 ID |
| server_profile_id | BIGINT | 使用的服务器对象内部 ID |
| status | enum | `queued` / `running` / `succeeded` / `failed` / `timeout` / `cancelled` |
| command_summary | string | 命令摘要 |
| started_at | datetime | 开始时间 |
| finished_at | datetime | 结束时间 |
| exit_code | int | 退出码 |
| error_message | string | 错误信息 |

### 6.2 ExecutionLog

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| run_id | BIGINT | 执行记录内部 ID |
| ts | datetime | 时间 |
| stream | enum | `stdout` / `stderr` / `system` |
| content | text | 日志内容 |
| seq | int | 顺序号 |

## 7. 资源锁模型

### 7.1 ResourceLock

用于避免多子任务抢同一张 GPU。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| server_profile_id | BIGINT | 被锁定的逻辑服务器内部 ID |
| physical_server_id | BIGINT | 物理服务器内部 ID |
| gpu_ids | string | 被锁 GPU |
| owner_type | enum | `subtask` / `manual` |
| owner_id | BIGINT | 子任务内部 ID |
| status | enum | `active` / `released` |
| locked_at | datetime | 锁定时间 |
| released_at | datetime | 释放时间 |

锁规则：

- 同一 PhysicalServer 下，GPU IDs 有交集则不能同时训练。
- ServerProfile 可作为调度粒度，但锁判断必须回到物理 GPU。
- 子任务结束、失败或停止后释放锁。
- 如果远程会话异常，锁不能立即自动释放，应通过进程探测确认训练是否仍在运行。

## 8. 远程命令任务模型

### 8.1 RemoteCommandTask

远程执行插件内部的队列任务。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 内部存储 ID，雪花算法 long，不对外展示 |
| session_generation | int | 会话代号 |
| command_group | text | 命令组 |
| timeout_ms | int | 超时时间 |
| status | enum | `queued` / `running` / `succeeded` / `failed` / `session_reset` |
| stdout | text | 输出 |
| stderr | text | 错误输出 |
| exit_code | int | 退出码 |

注意：

- 这是执行器内部模型，不应暴露为核心业务对象。
- 会话重建后旧队列丢失，业务层应根据 ExecutionRun 状态决定是否重试。
