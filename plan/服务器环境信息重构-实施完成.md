# 服务器环境信息重构 - 实施完成

## 概述

优化服务器探测信息的展示方式，从扁平的 Info 卡片改为结构化的卡片布局，新增 CPU/内存硬件信息，修复 GPU 数量和版本显示问题。

## 主要改动

### 1. 后端改动

#### 1.1 数据库模型 (`backend/app/models.py`)
- 新增 3 个 JSON 字段存储结构化探测数据：
  - `gpu_json`: GPU 详细信息（型号、物理数量、可见 ID、驱动、CUDA 版本）
  - `hardware_json`: 硬件信息（CPU、内存、磁盘）
  - `finetune_env_json`: 微调环境信息（Python、PyTorch、Transformers、LLaMA-Factory 版本）

#### 1.2 数据库迁移 (`backend/app/db/session.py`)
- 新增 `_ensure_sqlite_columns()` 自动迁移函数
- 为现有数据库自动添加 3 个新列

#### 1.3 探测脚本 (`backend/app/services/script_service.py`)
- **硬件探测脚本增强**：
  - 新增 CPU 型号、核心数、线程数探测
  - 新增内存总量、已用量、使用率探测
  - 修复 GPU 数量显示：区分物理总数和可见 ID 列表
  - 新增 CUDA 版本探测
- **微调环境探测脚本增强**：
  - 使用正则提取 LLaMA-Factory 版本号，过滤装饰性文本
  - 版本提取规则：`version\s+([\d.]+(?:\.(?:dev|post|a|b|rc)\d+)?)`

#### 1.4 数据归一化 (`backend/app/services/server_service.py`)
- `_normalize_hardware()`: 输出结构化 `gpuInfo` 和 `hardwareInfo`
- `_normalize_finetune_env()`: 输出结构化 `finetuneEnvInfo`
- `server_to_out()`: 合并新旧字段，保持向后兼容
- `_apply_successful_probe_items()`: 保存结构化数据到新字段

#### 1.5 API Schema (`backend/app/schemas.py`)
- `ServerOut` 新增 3 个嵌套字段：`gpuInfo`、`hardwareInfo`、`finetuneEnvInfo`
- 保留旧字段（`gpu`、`cuda`、`disk` 等）用于向后兼容

#### 1.6 启动清理 (`backend/app/main.py`)
- 每次启动时清空 `ServerProbeTask` 和 `ServerProbeItem` 表
- 确保使用最新数据结构重新探测

### 2. 前端改动

#### 2.1 主题配置 (`src/styles/themes.js`)
- 为 light/dark 主题各新增 `envCards` 配色方案
- 包含卡片背景、边框、文字、进度条、徽章等样式

#### 2.2 服务器页面 (`src/pages/ServersPage.jsx`)

**新增组件**：
- `EnvCard`: 环境信息卡片容器（带图标、标题、右上角徽章）
- `EnvBadge`: 状态徽章（支持 green/blue/amber/slate 四种色调）
- `DetailRow`: 详情行（标签-值对，支持 loading 骨架屏）
- `HardwareMetric`: 硬件指标卡（带进度条，用于 CPU/内存/磁盘）
- `MiniProgress`: 迷你进度条组件

**新增图标**：
- `IconServer`: 服务器图标
- `IconCpu`: CPU 图标
- `IconZap`: GPU 闪电图标
- `IconLayers`: 层级图标（微调环境）
- `IconRefreshCw`: 刷新图标
- `IconCheckCircle`: 勾选圆圈图标

**环境信息区域重构**：
1. **顶部标题栏**：
   - 左侧：服务器图标 + "环境信息"标题
   - 右侧：状态徽章 + 最近检测时间 + 重新检测按钮

2. **硬件信息**（直接展示，无外层卡片包裹）：
   - CPU：核心数/线程数 + 型号
   - 内存：已用/总量 + 使用率进度条
   - 磁盘：已用/总量 + 使用率进度条

3. **GPU 资源卡片**：
   - 显卡型号、可见编号、驱动版本、CUDA 版本
   - 右上角显示 GPU 物理数量徽章

4. **微调环境卡片**：
   - Python、PyTorch（带 CUDA 徽章）、Transformers、LLaMA-Factory 版本
   - 右上角显示工具名称徽章

**数据结构适配**：
- `makeEmptyEnvInfo()`: 新增 `gpuInfo`、`hardwareInfo`、`finetuneEnvInfo` 字段
- `normalizeEnvInfo()`: 合并新旧字段结构
- `applyProbeTaskToModal()`: 适配新的探测结果格式

**服务器列表表格优化**：
- 7 列布局：服务器名称、连接地址、连接方式、状态、微调工具、显卡型号、磁盘
- 显卡型号列：显示物理数量 + 型号（如 `8×A800-SXM4-80GB`）
- 磁盘列：显示已用/总量 + 进度条
- 微调工具列：工具名称 + 版本号

#### 2.3 全局样式 (`index.html`)
- 新增 `@keyframes pulse` 动画，用于 loading 骨架屏效果

## 解决的问题

1. ✅ GPU 数量显示错误（只显示选中数量，现显示物理总数）
2. ✅ 缺少 CPU/内存硬件信息
3. ✅ LLaMA-Factory 版本显示装饰性文本（现使用正则提取纯版本号）
4. ✅ 信息展示过于扁平，缺乏结构化
5. ✅ 磁盘和内存缺少可视化进度条

## 验证步骤

1. 重启后端服务：`cd backend && uvicorn app.main:app --reload --host 127.0.0.1 --port 30001`
2. 重启前端服务：`npm run dev`
3. 访问服务器列表页面，验证表格 7 列布局正常
4. 点击编辑服务器，验证环境信息区域 3 卡片布局
5. 点击"连通性测试"按钮，验证探测结果显示正确
6. 切换 light/dark 主题，验证配色方案
7. 验证 GPU 物理数量、LLaMA-Factory 版本号显示正确
