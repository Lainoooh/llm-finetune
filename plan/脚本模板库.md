# 脚本模板库

## 1. 脚本模板配置规范

### 1.1 核心设计原则

#### 变量注入机制

**不使用模板占位符**（如 `{{variable}}`），而是在 Python 脚本开头直接注入变量定义。

**工作流程：**
1. 用户调用脚本时传入参数：`{"work_dir": "/home/jovyan/work", "gpu_ids": "0"}`
2. `render_script()` 函数将参数转换为 Python 变量定义并注入到脚本开头
3. 脚本中直接使用这些变量

**示例：**

调用：
```python
render_script(script, {"work_dir": "/home/jovyan/work", "gpu_ids": "0"})
```

生成的脚本：
```python
python3 - <<'PY'
WORK_DIR = '/home/jovyan/work'
GPU_IDS = '0'

# 脚本逻辑直接使用 WORK_DIR 和 GPU_IDS
import os
os.makedirs(WORK_DIR, exist_ok=True)
PY
```

#### JSON 输出规范

所有脚本必须使用 JSON 边界标记包围输出：

```python
print("__JSON_START__")
print(json.dumps(result, ensure_ascii=False))
print("__JSON_END__")
```

执行器会使用 `rfind()` 提取最后一次出现的标记之间的内容（避免匹配输入回显）。

#### 避免转义冲突

**问题：** Docker 格式字符串 `{{.Names}}` 会与模板语法冲突

**解决方案：** 使用 Python 变量存储

```python
# ✅ 正确
docker_format = "{{.Names}}"
cmd = "docker ps --format '" + docker_format + "' | grep xxx"

# ❌ 错误（会被模板渲染器处理）
cmd = f"docker ps --format '{{.Names}}' | grep xxx"
```

### 1.2 标准模板结构

```python
SCRIPT_TEMPLATE = r'''
python3 - <<'PY'
import json, os, subprocess, sys, time

# 变量将在这里注入（由 render_script 自动添加）

def run(cmd, timeout=5, name="cmd"):
    started = time.time()
    try:
        result = subprocess.check_output(cmd, shell=True, stderr=subprocess.STDOUT, text=True, timeout=timeout).strip()
        return result
    except subprocess.TimeoutExpired:
        return ""
    except Exception:
        return ""

# 脚本逻辑
payload = {
    "status": "success",
    "data": {}
}

print("__JSON_START__")
print(json.dumps(payload, ensure_ascii=False))
print("__JSON_END__")
PY
'''
```

**必需元素：**
1. 以 `python3 - <<'PY'` 开头
2. 在开头预留变量注入位置（注释标注）
3. 使用 `__JSON_START__` 和 `__JSON_END__` 包围输出
4. 以 `PY` 结束 heredoc

### 1.3 参数 Schema 定义

每个脚本模板必须定义参数 schema：

```json
{
  "required": ["work_dir"],
  "properties": {
    "work_dir": {
      "type": "path",
      "description": "工作目录"
    },
    "gpu_ids": {
      "type": "gpu_ids",
      "description": "显卡设备编号，格式：0,1,2"
    },
    "container_name": {
      "type": "text",
      "description": "Docker 容器名称"
    }
  }
}
```

**参数类型：**
- `path`：文件路径
- `text`：文本字符串
- `gpu_ids`：GPU 编号列表
- `number`：数字
- `boolean`：布尔值

### 1.4 render_script() 实现

```python
def render_script(script: ScriptTemplate, params: dict[str, Any]) -> str:
    schema = json.loads(script.param_schema_json or "{}")
    required = schema.get("required", [])
    
    # 验证必需参数
    for key in required:
        if key not in params or params[key] in (None, ""):
            raise ValueError(f"Missing required script param: {key}")
    
    # 验证参数是否在允许列表中
    allowed = set(schema.get("properties", {}).keys())
    for key in params:
        if allowed and key not in allowed:
            raise ValueError(f"Unknown script param: {key}")
    
    # 构建变量定义（Python 代码）
    var_definitions = []
    for key, value in params.items():
        var_name = key.upper()  # work_dir → WORK_DIR
        var_definitions.append(f"{var_name} = {repr(value)}")
    
    var_block = "\n".join(var_definitions)
    
    # 在 Python heredoc 开头注入变量定义
    if "python3 - <<'PY'" in script.template:
        return script.template.replace(
            "python3 - <<'PY'\n",
            f"python3 - <<'PY'\n{var_block}\n\n"
        )
    
    return script.template
```

#### server.probe_hardware

**功能：** 创建工作目录，探测显卡、驱动、磁盘和目录权限

**参数：**
- `work_dir` (必需)：工作目录路径
- `gpu_ids` (可选)：显卡设备编号

**超时：** 45 秒  
**风险等级：** low

**模板代码：**

```python
SERVER_HARDWARE_PROBE_TEMPLATE = r'''
python3 - <<'PY'
import json, os, shlex, subprocess, sys, time

# 变量将在这里注入

timings = {}

def run(cmd, timeout=5, name="cmd"):
    started = time.time()
    try:
        result = subprocess.check_output(cmd, shell=True, stderr=subprocess.STDOUT, text=True, timeout=timeout).strip()
        return result
    except subprocess.TimeoutExpired:
        return ""
    except Exception:
        return ""
    finally:
        timings[name] = round(time.time() - started, 3)

def disk(path):
    out = run(f"df -B1 --output=size,used,avail,pcent,target {path!r} 2>/dev/null | tail -1", timeout=3, name="disk")
    parts = out.split()
    if len(parts) >= 5:
        return {
            "size": int(parts[0]),
            "used": int(parts[1]),
            "avail": int(parts[2]),
            "percent": parts[3],
            "target": parts[4],
        }
    return None

def split_ids(value):
    return [item.strip() for item in value.split(",") if item.strip()]

def detect_accelerators():
    nvidia_csv = run("nvidia-smi --query-gpu=index,name,uuid,memory.total,memory.used --format=csv,noheader,nounits", timeout=6, name="nvidia_smi_query")
    if nvidia_csv:
        return {
            "vendor": "nvidia",
            "runtime": "cuda",
            "driver": run("nvidia-smi --query-gpu=driver_version --format=csv,noheader,nounits | head -1", timeout=4, name="nvidia_driver"),
            "csv": nvidia_csv,
        }
    return {"vendor": "unknown", "runtime": "-", "driver": "-", "csv": ""}

# 创建工作目录
try:
    os.makedirs(WORK_DIR, exist_ok=True)
except Exception:
    pass

accelerator = detect_accelerators()
accelerator_ids = split_ids(GPU_IDS)
if accelerator_ids:
    accelerator_count = len(accelerator_ids)
else:
    csv_lines = [line for line in accelerator["csv"].splitlines() if line.strip()]
    accelerator_count = len(csv_lines)

payload = {
    "hostname": run("hostname", timeout=2, name="hostname"),
    "pwd": os.getcwd(),
    "work_dir": WORK_DIR,
    "work_dir_exists": os.path.exists(WORK_DIR),
    "work_dir_writable": os.access(WORK_DIR, os.W_OK) if os.path.exists(WORK_DIR) else False,
    "driver": accelerator["driver"],
    "gpus_csv": accelerator["csv"],
    "selected_gpu_ids": GPU_IDS,
    "accelerator_vendor": accelerator["vendor"],
    "accelerator_runtime": accelerator["runtime"],
    "accelerator_driver": accelerator["driver"],
    "accelerators_csv": accelerator["csv"],
    "accelerator_ids": GPU_IDS,
    "accelerator_count": accelerator_count,
    "disk": disk(WORK_DIR if os.path.exists(WORK_DIR) else "/"),
    "timings": timings,
}
print("__JSON_START__")
print(json.dumps(payload, ensure_ascii=False))
print("__JSON_END__")
PY'''
```

#### server.probe_finetune_env

**功能：** 进入微调工具容器探测 Python、PyTorch、Transformers 和微调工具版本

**参数：**
- `container_name` (必需)：微调工具容器名

**模板代码：**

```python
SERVER_FINETUNE_ENV_PROBE_TEMPLATE = r'''python3 - <<'PY'
import json, os, shlex, subprocess, time

# 变量将在这里注入

timings = {}

def run(cmd, timeout=8, name="cmd"):
    started = time.time()
    try:
        result = subprocess.check_output(cmd, shell=True, stderr=subprocess.STDOUT, text=True, timeout=timeout).strip()
        return result
    except subprocess.TimeoutExpired:
        return ""
    except Exception:
        return ""
    finally:
        timings[name] = round(time.time() - started, 3)

def emit(payload):
    payload["timings"] = timings
    print("__JSON_START__")
    print(json.dumps(payload, ensure_ascii=False))
    print("__JSON_END__")

# 处理变量
container = CONTAINER_NAME.strip() if 'CONTAINER_NAME' in dir() else ""
tool_name = FINETUNE_TOOL_NAME.strip() if 'FINETUNE_TOOL_NAME' in dir() else "LLaMA-Factory"
tool_name = tool_name or "LLaMA-Factory"

if not container:
    emit({"ok": False, "error": "微调工具容器名不能为空", "container_name": container})
    raise SystemExit(0)

docker_format = "{{.Names}}"
exists = run("docker ps --format '" + docker_format + "' | grep -Fx " + shlex.quote(container), timeout=5, name="container_lookup")
if not exists:
    emit({"ok": False, "error": f"没有找到 {container} 容器", "container_name": container})
    raise SystemExit(0)

env_json = run(f"""docker exec {shlex.quote(container)} python3 -c "
import json, sys

def version(module):
    try:
        mod = __import__(module)
        return str(getattr(mod, '__version__', '-'))
    except Exception as exc:
        return f'missing: {{exc}}'

result = {{
    'python': sys.version.split()[0],
    'pytorch': version('torch'),
    'transformers': version('transformers'),
}}
print(json.dumps(result, ensure_ascii=False))
" """, timeout=10, name="finetune_env")
try:
    env_info = json.loads(env_json) if env_json else {}
except Exception:
    env_info = {}

tool_version = run(f"docker exec {shlex.quote(container)} bash -c 'llamafactory-cli version 2>/dev/null || python3 -m llamafactory.cli version 2>/dev/null'", timeout=10, name="finetune_tool")

emit({
    "ok": True,
    "container_name": container,
    "finetune_tool_name": tool_name,
    "finetune_tool_version": tool_version or "-",
    "python": env_info.get("python", "-"),
    "pytorch": env_info.get("pytorch", "-"),
    "transformers": env_info.get("transformers", "-"),
})
PY'''
```

```python
SUBTASK_READ_STATUS_TEMPLATE = r'''
python3 - <<'PY'
import json, os

# 变量将在这里注入

def pid_alive(pid):
    try:
        os.kill(pid, 0)
        return True
    except Exception:
        return False

payload = {
    "pid": None,
    "pid_alive": False,
    "status_file": None,
    "status": "unknown",
    "exit_code": None,
}

pid_file = os.path.join(SUBTASK_DIR, "run.pid")
status_file = os.path.join(SUBTASK_DIR, "status.json")

if os.path.exists(pid_file):

if os.path.exists(status_file):
    data = json.load(open(status_file))
    payload["status_file"] = data
    payload["status"] = data.get("status", "unknown")
    payload["exit_code"] = data.get("exit_code")
elif payload["pid_alive"]:
    payload["status"] = "running"

print("__JSON_START__")
print(json.dumps(payload, ensure_ascii=False))
print("__JSON_END__")
PY
'''
```

```python
# 变量将在这里注入

log_path = os.path.join(SUBTASK_DIR, LOG_FILE)
offset = int(OFFSET)

result = {
    "offset": offset,
    "next_offset": offset,
    "content_b64": "",
    "exists": os.path.exists(log_path)
}

if result["exists"]:
    size = os.path.getsize(log_path)
    if offset > size:
        offset = 0
    with open(log_path, "rb") as f:
        f.seek(offset)
        data = f.read(256 * 1024)  # 最多读取 256KB
        result["offset"] = offset
        result["next_offset"] = offset + len(data)
        result["content_b64"] = base64.b64encode(data).decode()

print("__JSON_START__")
print(json.dumps(result, ensure_ascii=False))
print("__JSON_END__")
PY
'''
```

## 3. 新增脚本指南

### 3.1 创建新脚本模板

**步骤：**

1. **确定脚本 key**
   - 格式：`category.action`
   - 示例：`server.probe_hardware`、`subtask.start_train`

2. **定义参数 schema**
   ```python
   param_schema_json = json.dumps({
       "required": ["param1"],
       "properties": {
           "param1": {"type": "text", "description": "参数1说明"},
           "param2": {"type": "number", "description": "参数2说明"}
       }
   }, ensure_ascii=False)
   ```

3. **编写 Python heredoc 模板**
   ```python
   TEMPLATE = r'''
   python3 - <<'PY'
   import json, os
   
   # 变量将在这里注入
   
   # 脚本逻辑
   result = {"status": "success"}
   
   print("__JSON_START__")
   print(json.dumps(result, ensure_ascii=False))
   print("__JSON_END__")
   PY
   '''
   ```

4. **在模板开头标注变量注入位置**
   - 使用注释：`# 变量将在这里注入`
   - `render_script()` 会在此位置插入变量定义

5. **使用 JSON 边界标记输出**
   - 必须使用 `__JSON_START__` 和 `__JSON_END__`
   - 使用 `json.dumps()` 确保格式正确

6. **设置合理超时和风险等级**
   - 超时：根据操作复杂度设置（10-60 秒）
   - 风险等级：`low` / `medium` / `high`

7. **添加到 BUILTIN_SCRIPTS**
   ```python
   BUILTIN_SCRIPTS = [
       {
           "key": "category.action",
           "name": "脚本名称",
           "category": "category",
           "description": "脚本描述",
           "template": TEMPLATE,
           "param_schema_json": param_schema_json,
           "timeout_ms": 30_000,
           "risk_level": "low",
       },
   ]
   ```

### 3.3 注意事项

**必须遵守：**

1. ❌ **不要使用 `{{variable}}` 占位符**
   - 会与 Docker 格式字符串冲突
   - 正则替换不安全

2. ✅ **Docker 格式字符串存储为 Python 变量**
   ```python
   docker_format = "{{.Names}}"
   cmd = f"docker ps --format '{docker_format}'"
   ```

3. ✅ **避免使用环境变量传参**
   - 不要使用 `os.environ.get("PARAM")`
   - 直接使用注入的 Python 变量

4. ✅ **确保脚本是原子操作**
   - 单个脚本应该完成一个完整的操作
   - 不要在脚本中启动长时间运行的进程（除非是后台任务）

5. ✅ **超时设置要合理**
   - 探测类：10-30 秒
   - 配置同步：30-60 秒
   - 启动/停止：30 秒
   - 长时间操作应该拆分为后台任务

6. ✅ **错误处理**
   - 使用 try-except 捕获异常
   - 在 JSON 输出中包含错误信息
   ```python
   try:
       # 操作
       payload = {"ok": True, "data": result}
   except Exception as e:
       payload = {"ok": False, "error": str(e)}
   ```

## 4. FAQ

### Q1: 为什么不用 `{{param}}` 占位符？

**A:** 会与 Docker 格式字符串 `{{.Names}}` 冲突，且正则替换不安全。使用 Python 变量注入更清晰、更安全。

### Q2: 如何处理 Docker 格式字符串？

**A:** 存储为 Python 变量：

```python
docker_format = "{{.Names}}"
cmd = f"docker ps --format '{docker_format}' | grep xxx"
```

### Q3: 脚本超时了怎么办？

**A:** 
1. 检查是否是长时间操作（如训练），考虑拆分为后台任务
2. 增加超时时间（但不要超过 60 秒）
3. 优化脚本逻辑，减少不必要的操作

### Q4: 如何调试脚本？

**A:** 
1. 使用测试脚本直接在 Jupyter 上执行
2. 查看 `raw_output` 了解完整输出
3. 检查 JSON 边界标记是否正确
4. 验证变量注入是否成功

```python
result = await session.run_script(rendered, timeout_ms=30000)
print("raw_output:")
print(result.raw_output)
```

```python
params = {
```

### Q6: 脚本可以返回非 JSON 输出吗？

**A:** 不推荐。所有脚本应该返回结构化 JSON 输出，便于解析和错误处理。如果必须返回原始文本，使用 base64 编码：

```python
import base64
payload = {
    "content_b64": base64.b64encode(raw_text.encode()).decode()
}
```

### Q7: 如何在脚本中执行多个命令？

**A:** 使用辅助函数：

```python
def run(cmd, timeout=5):
    try:
        return subprocess.check_output(cmd, shell=True, text=True, timeout=timeout).strip()
    except Exception:
        return ""

result1 = run("command1")
result2 = run("command2")
```

### Q8: 脚本可以修改远程文件吗？

**A:** 可以，但要注意：
1. 设置合适的风险等级（`medium` 或 `high`）
2. 在描述中明确说明会修改哪些文件
3. 提供回滚机制（如果可能）
4. 记录操作日志
