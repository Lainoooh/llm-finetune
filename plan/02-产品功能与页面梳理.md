## 1. 产品目标

本系统是一个可视化微调平台，目标是让用户以页面化方式管理 LLaMA-Factory 微调流程：

- 管理训练服务器和 GPU 资源。
- 创建微调任务。
- 在任务下创建多个子任务。
- 每个子任务绑定一组 GPU 和一套训练配置。
- 远程执行训练、实时查看日志。
- 汇总训练结果与评测结果，辅助选择最佳模型。

## 3. 当前页面能力盘点

### 3.1 总览页

文件：`src/pages/Dashboard.jsx`

当前能力：

- 展示远程服务器数量。
- 展示子任务总数。
- 展示训练中和失败任务数量。
- 展示训练 Loss 趋势图。
- 可跳转综合对比。

后续增强：

- 展示 GPU 空闲/占用数量。
- 展示当前运行中的训练任务。
- 展示近期失败原因和资源告警。
- 展示磁盘使用率风险。

### 3.2 服务器管理页

文件：`src/pages/ServersPage.jsx`

当前能力：

- 服务器列表展示。
- 按在线/离线筛选。
- 搜索服务器名称和地址。
- 新增/编辑服务器弹窗。
- 配置名称、账号、密码、地址、工作目录、GPU IDs、微调工具。
- 展示 GPU、CUDA、PyTorch、微调工具版本、磁盘、状态。
- 连通性检查当前为 mock。

后续目标：

- 配置物理服务器连接方式。
- 探测 GPU 数量、型号、显存、驱动、CUDA、PyTorch、LLaMA-Factory。
- 支持部署或校验 LLaMA-Factory 容器镜像。
- 支持选择工作目录。
- 支持按 GPU 拆分逻辑服务器对象。
- 支持 GPU 占用状态和训练冲突提示。

### 3.3 微调任务列表页

文件：`src/pages/TaskListPage.jsx`

当前能力：

- 展示微调任务列表。
- 展示任务状态、模型名、基模、子任务数、运行中数量。
- 支持搜索和状态筛选。
- 新建任务、编辑任务、复制任务、删除任务均为待实现或 mock。

后续目标：

- 创建任务时配置目标模型名、基座模型、任务描述和默认输出路径。
- 支持任务模板复制。
- 支持任务状态从子任务状态聚合。
- 支持归档任务和导出任务配置。

### 3.4 任务详情页

文件：`src/pages/TaskDetailPage.jsx`

当前能力：

- 展示单个任务头部信息。
- 展示子任务状态统计。
- 子任务列表支持搜索、状态筛选、分页。
- 支持复制子任务、删除子任务。
- 支持新建子任务。
- “并行启动任务”当前只是本地状态变更。

后续目标：

- 新建子任务时选择服务器对象。
- 并行启动时校验资源锁，只有 GPU 空闲的子任务进入运行。
- 子任务状态由执行记录驱动，而不是前端直接修改。
- 支持停止、重试、失败原因查看。

### 3.5 子任务配置页

文件：`src/pages/SubtaskPage.jsx`

当前能力：

- 选择远程服务器。
- 展示所选服务器的连接、GPU、CUDA、微调工具、磁盘信息。
- 基础配置：子任务名称、GPU、基模路径、输出目录。
- 数据集：训练集、评测集、`dataset_info.json` 展示。
- 训练参数：可视化参数和 YAML 模式。
- 远程目录：输出目录和目录树 mock。
- 训练日志：训练日志逐步展示 mock。
- 测试评测：Adapter 加载测试、业务评测脚本、结果可视化。

后续目标：

- 子任务配置持久化。
- 根据服务器对象自动带出 GPU IDs 和工作目录。
- 将可视化参数和 YAML 双向转换。
- 支持上传/选择训练数据集。
- 支持生成 LLaMA-Factory 训练 YAML。
- 支持同步配置到远程工作目录。
- 支持启动训练、停止训练、日志流式读取、刷新远程目录。
- 支持评测脚本执行和结果解析。

### 3.6 综合对比页

文件：`src/pages/ComparePage.jsx`

当前能力：

- 判断是否所有子任务结束。
- 展示子任务数量、成功数量、比较状态。
- 展示 Loss 对比和评测结果对比 mock。
- 展示参数与结果汇总。
- 导出报告和执行综合比较为 mock。

后续目标：

- 从训练日志或指标文件生成 Loss 曲线。
- 从评测结果文件生成指标对比。
- 支持选择参与对比的子任务。
- 支持导出 HTML/PDF/Markdown 报告。
- 标记最佳子任务或最佳 Adapter。

## 4. 当前数据流

当前数据完全保存在 React 内存中：

```text
mockData.js
  -> App.jsx useState(initialServers, initialTask)
  -> 页面 props 传递
  -> 页面内 setState 修改
```

问题：

- 刷新页面后数据丢失。
- 无真实服务器连接。
- 无任务执行记录。
- 无资源锁。
- 无训练日志来源。
- 无文件和模型产物管理。

## 5. 目标数据流

```text
前端页面
  -> src/api/*.js
  -> 后端 API
  -> 数据库
  -> 执行器适配层
  -> 远程 LLaMA-Factory 容器
```

示例：点击服务器连通性检查

```text
ServersPage.testServerConnection
  -> POST /api/servers/:id/probe
  -> backend ServerService.probeServer
  -> RemoteExecutor.run(probe script)
  -> JupyterTerminalExecutor
  -> stdout JSON
  -> Parser.normalizeServerEnv
  -> 更新 server.env_snapshot
  -> 返回前端
```

示例：启动子任务训练

```text
SubtaskPage.startTraining
  -> POST /api/subtasks/:id/start
  -> 校验服务器对象在线、GPU 未占用
  -> 写入 execution_run
  -> 锁定 GPU
  -> 生成 YAML 和启动脚本
  -> RemoteExecutor.enqueue(script)
  -> 日志流进入 execution_log
  -> 前端订阅 /api/subtasks/:id/logs
```
