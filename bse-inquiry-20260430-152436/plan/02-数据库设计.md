## 1. 数据库概述

### 1.1 技术选型
- **数据库**: SQLite 3
- **模式**: WAL (Write-Ahead Logging)
- **外键**: 启用
- **连接池**: 上下文管理器模式

### 1.2 数据库文件
- **开发环境**: `backend/app/data/bse.db`
- **初始化脚本**: `backend/app/data/init.sql`

## 2. 表结构设计

### 2.1 用户认证模块

#### users（用户表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK AUTOINCREMENT | 用户 ID |

| is_active | BOOLEAN | DEFAULT 1 | 是否启用 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

#### user_sessions（用户会话表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK AUTOINCREMENT | 会话 ID |
| user_id | INTEGER | FK→users(id) | 用户 ID |

### 2.2 模型管理模块

#### models（模型配置表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK AUTOINCREMENT | 模型 ID |
| vendor | TEXT | NOT NULL | 供应商：aliyun/openai |
| model_type | TEXT | NOT NULL | 类型：llm |
| model_name | TEXT | NOT NULL | 模型名称 |
| api_name | TEXT | NOT NULL | API 名称：dashscope |
| api_key | TEXT | NOT NULL | API 密钥（加密存储） |
| endpoint_url | TEXT | NOT NULL | API 端点 URL |
| max_input_tokens | INTEGER | DEFAULT 32768 | 最大输入 Token |
| max_output_tokens | INTEGER | DEFAULT 8192 | 最大输出 Token |
| is_active | BOOLEAN | DEFAULT 1 | 是否启用 |
| is_default | BOOLEAN | DEFAULT 0 | 是否默认模型 |
| config | TEXT | | JSON 配置（Prompt 等） |
| purpose | TEXT | DEFAULT NULL | 用途：risk_judgment/risk_signal/inquiry_logic/inquiry_item/common |
| parent_model_id | INTEGER | FK→models(id) | 父模型 ID（NULL 表示父模型） |
| display_name | TEXT | DEFAULT NULL | 显示名称 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

**父子模型关系**：
- `parent_model_id = NULL` 且 `purpose = NULL` → 父模型
- `parent_model_id = <parent_id>` 且 `purpose != NULL` → 子模型
- 每个父模型最多 5 个子模型（对应 5 个 purpose）

## 3. 表关系图

```
users
  ├─→ user_sessions (1:N)
  ├─→ conversations (1:N) [owner_id]
  └─→ messages (1:N)

conversations
  ├─→ conversation_members (1:N)
  ├─→ messages (1:N)
  └─→ tasks (1:N)

tasks
  ├─→ annual_report_files (1:1)
  ├─→ workflow_steps (1:N)
  ├─→ user_decisions (1:N)
  ├─→ inquiry_letters (1:N)
  ├─→ risk_signals (1:N)
  └─→ indicator_values (1:N)

models
  ├─→ models (1:N) [parent_model_id, 父子关系]
  └─→ tasks (1:N) [model_id]

rdu_metrics_standard (独立表, 112 项标准指标)
  └─→ rdu_metric_values (1:N) [metric_code]

rdu_risk_signals (独立表, 71 项风险信号)
  └─→ 通过 metric_codes JSON 关联 rdu_metrics_standard
```

## 4. 主键策略

| 策略 | 适用表 |
|------|--------|
| INTEGER PK AUTOINCREMENT | users, user_sessions, models, annual_report_files, workflow_steps, user_decisions, inquiry_letters, indicator_values |
| TEXT PK (UUID) | conversations, messages, tasks, risk_signals |
| BIGINT PK (雪花算法) | rdu_metrics_standard (1-112), rdu_risk_signals (113-183), rdu_metric_values (184-295) |
